# 安装

## 1. 将仓库克隆到本地 Git 的指令：

<img src="https://i.ibb.co/nzgXRQ1/git-clone.png">

<br>

**克隆仓库：** 

<br>

要开始使用该项目，请使用以下终端命令之一将此仓库克隆到您的本地 Git：

  - 克隆仓库并获取所有分支。

    ```
    git clone https://github.com/0ktim/XSU-9-Class.git
    ```
  - 克隆仓库并获取所有分支，同时立即切换到特定分支。

    ```
    git clone --branch ИМЕ-НА-КЛОНА https://github.com/0ktim/XSU-9-Class.git
    ```

  - 克隆仓库且仅获取单个分支。

    ```
    git clone --branch ИМЕ-НА-КЛОНА --single-branch https://github.com/0ktim/XSU-9-Class.git
    ```
<br>
<br>

## 2. 将更改推送至 GitHub 仓库的指令：


<img src="https://i.ibb.co/RyPzYKs/git-push.png">

<br>

**推送仓库：** 

<br>

  1. **检查文件状态：**
     - 在添加、提交和推送更改之前，使用 `git status` 命令检查仓库中的文件状态会很有帮助。该命令将显示仓库中现有的更改，以及哪些文件被添加、修改或删除的信息。

        ```
        git status
        ```

  1. **添加更改：**
     - 在推送更改之前，必须将其添加到 Git 索引中。这可以通过 `git add .` 命令完成，其中 `.` 表示添加所有更改。

        ```
        git add .
        ```
        
  1. **提交更改：**
     - 将更改添加到索引后，必须使用 `git commit -m "提交信息"` 命令对其进行提交。请将 "提交信息" 替换为描述您所做更改的信息。

        ```
        git commit -m "提交信息"
        ```

  1. **推送更改：**
     - 提交更改后，可以使用 `git push` 命令将其推送到 GitHub 仓库。

        ```
        git push
        ```
